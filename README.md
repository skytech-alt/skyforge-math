# skf-math

Супер-расширенная математика для SkyForge. Всё, что нужно: тригонометрия, статистика, комбинаторика, комплексные числа, геометрия.

Автор: **SkyMonder**

## Установка

Пакет использует стандартные модули Python (`math`, `statistics`, `cmath`), которые уже входят в Python. Ничего дополнительно ставить не нужно.

    SkyForge install skf-math --trust

## Что внутри

### Базовые операции
`абсолют()`, `знак()`, `округлить()`, `пол()`, `потолок()`, `остаток()`, `модуль()`

### Степени и корни
`степень()`, `квадрат()`, `куб()`, `корень()`, `корень_n()`, `гипотенуза()`, `экспонента()`

### Логарифмы
`логарифм()`, `логарифм10()`, `логарифм2()`, `логарифм_по()`

### Тригонометрия
`синус()`, `косинус()`, `тангенс()`, `арксинус()`, `арккосинус()`, `арктангенс()`, `арктангенс2()`, `в_радианы()`, `в_градусы()`

### Гиперболические функции
`синус_гип()`, `косинус_гип()`, `тангенс_гип()`

### Комбинаторика
`факториал()`, `сочетания()`, `размещения()`, `нод()`, `нок()`

### Простые числа
`простое_число?()`, `следующее_простое()`, `разложить_на_множители()`

### Статистика
`среднее()`, `медиана()`, `мода()`, `стандартное_отклонение()`, `дисперсия()`, `минимум()`, `максимум()`, `сумма()`, `произведение()`

### Комплексные числа
`комплекс()`, `модуль_комплексного()`, `фаза()`, `корень_комплексного()`

### Геометрия
`площадь_круга()`, `длина_окружности()`, `площадь_прямоугольника()`, `площадь_треугольника()`, `площадь_треугольника_по_сторонам()`, `объем_сферы()`, `объем_цилиндра()`, `объем_конуса()`

### Константы
`пи()`, `е()`, `тау()`, `бесконечность()`, `не_число()`

### Проверки
`конечное?()`, `бесконечное?()`, `не_число?()`, `близко?()`

## Примеры

```skyforge
подключить("skf-math")

лог(корень(144))                    // 12.0
лог(синус(30))                      // 0.5
лог(факториал(5))                   // 120
лог(нод(48, 36))                    // 12
лог(простое_число?(17))             // истина
лог(разложить_на_множители(100))    // [2, 2, 5, 5]
лог(среднее([1, 2, 3, 4, 5]))       // 3.0
лог(пи())                           // 3.141592653589793
лог(площадь_круга(5))               // 78.53981633974483
